锁相放大器 GUI — 绿色免安装包
================================

一、怎么用
----------
1. 把整个「LockinGUI」文件夹拷到目标电脑任意目录
2. 双击启动：
   - 启动_串口模式.bat   （默认，命令+数据都走板载 CH340 USB 串口，921600）
   - 启动_UDP模式.bat    （仅用于旧的以太网版 bit，命令+数据走网线）
   - 启动_演示模式.bat   （无板子，模拟数据）
   也可直接双击 LockinGUI.exe（等同串口模式）
   串口模式下界面会列出所有串口，CH340 自动排在最前并选中

二、目标电脑要求
----------------
- Windows 10 / 11 64 位
- 已安装 CH340 USB 串口驱动（设备管理器里显示 USB-SERIAL CH340 (COMx)）
- FPGA 需加载串口版 bit（PL 端 L17/M17 串口）
- 串口同一时间只能被一个程序打开：用 GUI 时请关闭串口助手 / SDK 程序
- 若用 UDP（旧以太网版 bit）：网卡静态 IP = 192.168.99.100，掩码 255.255.255.0
  FPGA 默认 IP = 192.168.99.10

三、注意
--------
- 必须保留整个文件夹，不要只拷单个 exe（依赖库在同目录）
- 首次被杀软拦截时，请「允许运行」
- 本包不含 Python，无需在目标机安装 Python

四、重新打包（开发机）
--------------------
在 lockin_gui 目录运行：build_portable.bat
