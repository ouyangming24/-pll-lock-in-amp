锁相放大器 GUI — 绿色免安装包
================================

一、怎么用
----------
1. 把整个「LockinGUI」文件夹拷到目标电脑任意目录
2. 双击启动：
   - 启动_UDP模式.bat   （默认，命令走 USB，数据走网线）
   - 启动_串口模式.bat   （命令+数据都走 FT245 USB）
   - 启动_演示模式.bat   （无板子，模拟数据）
   也可直接双击 LockinGUI.exe（等同 UDP 模式）

二、目标电脑要求
----------------
- Windows 10 / 11 64 位
- 已安装 FT245 / FTDI 驱动（串口或命令通道需要）
- 若用 UDP：网卡静态 IP = 192.168.99.100，掩码 255.255.255.0
  FPGA 默认 IP = 192.168.99.10

三、注意
--------
- 必须保留整个文件夹，不要只拷单个 exe（依赖库在同目录）
- 首次被杀软拦截时，请「允许运行」
- 本包不含 Python，无需在目标机安装 Python

四、重新打包（开发机）
--------------------
在 lockin_gui 目录运行：build_portable.bat
