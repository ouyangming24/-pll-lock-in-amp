## 2. 时钟与采样

| 项目 | 数值 | 说明 |
|---|---|---|
| 板载晶振 | 50 MHz（M19） | `sys_clk`，复位 `sys_rst_n`（J20） |
| 主时钟 | 65 MHz | `clk_wiz_0` 输出，全部处理逻辑、命令解析、串口都在这个域 |
| ADC 采样率 | 1 MSPS | AD7606C 每 65 拍转换一次（`speed_set = 64`） |
| CIC 抽取 | 65 | 65 MHz → 1 MHz，CIC(R=65, M=1, N=5) |
| IIR 采样率 | 1 MHz | TAU 换算截止频率时用这个 fs |
| DDS 相位累加器 | 48 位 | 频率字 = round(f × 2⁴⁸ / 65 MHz) |
| DAC 采样 | 65 MSPS | DAC904，14 位 offset binary |

AD7606C 的结果每 1 µs 更新一次，在 65 MHz 下保持 65 拍，下游按 65 MHz 与 DDS 混频，再由 CIC 抽到 1 MHz。
模拟带宽由 AD7606C 软件模式配置为 220 kHz，**有效输入信号频率上限约 200 kHz 量级**。

## 3. 八路 ADC 的用途

| 通道 | FPGA 信号 | 用途 | 上位机能读到的 |
|---|---|---|---|
| V1 | `adc_ch1` | 通道1 PLL 输入（锁定 F1） | 帧内 `adc[0]`（14 位瞬时值） |
| V2 | `adc_ch2` | 通道2 PLL 输入（锁定 F2） | 帧内 `adc[1]` |
| V3 | `adc_ch3` | 解调输入 CH3；DC 通路 | 帧内 `adc[2]` |
| V4 | `adc_ch4` | 解调输入 CH4 | 无 |
| V5 | `ad_v5` | 示波器 A 通道 | 示波器包（16 位） |
| V6 | `ad_v6` | 示波器 B 通道 | 示波器包（16 位） |
| V7、V8 | — | 已采集，未使用 | 无 |

量程全部是 ±10 V 单端。16 位码 1 LSB = 10/32768 V；送入处理链时取高 14 位，1 LSB = 10/8192 V。

## 4. 各功能块

### 4.1 通道1/2：闭环 PLL（`pll_loop.v`）

```
adc_in ──┬─▶ × sin ─▶ CIC ─▶ IIR(tau_x) ─▶ dc_x  (幅值, 判断是否锁定)
         └─▶ × cos ─▶ CIC ─▶ IIR(tau_y) ─▶ dc_y  (相位误差, 送 PI)
                ▲                              │
           DDS 本振 ◀──── pll_controller (PI + 扫频/锁定状态机) ◀┘
```

- 从扫频起点（通道1 `FRQ2`，通道2 `FRQ3`）开始扫频；|dc_y| 超过 `LOCKSWY` 门限进入锁定，
  锁定后靠 |dc_x| > `LOCKTHX` 维持；PI 参数 `KP`/`KI` 两通道共用。
- 输出：锁定频率字 `pll_freq_chN`（帧内回读）、本振相位 `pll_phase_chN`（供自动模式相干本振）、
  锁定标志（帧内 `lockFlags` bit0/bit1）。
- 通道1 IIR X 路的 valid（1 MHz）同时是**数据帧的快照触发信号**。

### 4.2 通道3：7 个振荡器解调（`lockin_psd.v` × 7）

```
OSRCk 选 CH3 / CH4 / CH3−CH4 ─▶ × 参考 sin/cos ─▶ CIC(65) ─▶ IIR 级联 (TAUk, ORDk 阶) ─▶ X / Y
```

- **参考信号来源**（`REFMODE`，全局）：
  - 0 手动：每个振荡器有独立 DDS，频率字 = `FRQxx` × `OHNk`
  - 1 自动：`coherent_harm_lo` 用两路 PLL 的相位直接合成 N·(n·θ1 + m·θ2)，与输入信号相干，
    系数 n/m 由 `OSCk` 设定，N 由 `OHNk` 设定
- **IIR**：`iir_lpf_cascade`，1~4 阶一阶 EMA 级联（6/12/18/24 dB/oct），档位 `tau` = 0..31，
  α = 2^-tau，每加 1 档时间常数约翻倍。
- **振荡器命名对应**（历史原因）：振荡器1/2/3 在 FPGA 里叫 `_21` / `_12` / `_11`
  （原意 2F1+F2、F1+2F2、F1+F2），振荡器4~7 直接叫 4~7。振荡器5/6/7 用 LUT 实现的 CIC 以省 DSP。
- **参考频率回读**：每个振荡器实际生效的参考频率字都打包进数据帧。

### 4.3 DC 通路

V3 直接进 CIC + IIR（`TAUDC`、`ORDDC`），不混频，得到 `ch3_dc`。增益比 X/Y 通路小 4096 倍
（少了 DDS 幅度 2¹³ 和混频系数 0.5），换算系数单独标定。

### 4.4 DAC 信号发生（`da_wave_send.v`）

- `DMOD` 从 7 个振荡器的参考正弦里选一路（与解调参考**同频同相**）。
- `DWAV=1` 时取该正弦的符号得到方波。
- 输出 = 参考 × `DAMP`/65536 + `DOFS`，超出 14 位范围限幅；65535 码 ≈ 3.0 Vpk 满量程。
- **DAC 没有独立频率**，频率跟随所选振荡器。

### 4.5 示波器（`scope_cap.v`）

- V5/V6 同时抓 1024 点，16 位；`SDEC` 抽取（每 n+1 点取 1 点，不平均）。
- 128 点预触发，触发点在下标 128；触发源 V5/V6 上升/下降沿，迟滞 64 LSB（约 20 mV）。
- Auto 模式等待超过 max(100 ms, 一屏时长) 无触发则强制触发（`forced=1`）；Normal 模式一直等。
- 抓满后由 `usb_commend` 整包上传（4114 字节，约 45 ms），上传期间不收命令。

### 4.6 通信（`uart_link.v` + `usb_commend.v`）

- `uart_link`：复用 `uart_rec` / `uart_send`，921600 8N1（实际 928571，误差 +0.76%）；
  256 字节 RX FIFO，因为 FPGA 发应答/示波器包期间不处理接收字节，而 PC 不会停发。
- `usb_commend`：
  - 解析 `NAME:十进制\r\n` 命令，回 `Command Success!` / `Command Error!`
  - `XYOUT` 后周期性打包数据帧（178 字节，含帧序号与 CRC16）
  - 有示波器数据时插入示波器包
  - 收到新命令字节会**打断正在发的数据帧**（形成半帧，靠 CRC 剔除）；示波器包不会被打断
- LED：`pl_led1`（P20）约 1 Hz 闪 = 逻辑在运行；`pl_led2`（P21）亮 50 ms = 串口有收发。

## 5. 上位机

### 5.1 Python GUI（`lockin_gui/`）

| 文件 | 作用 |
|---|---|
| `main.py` | 入口；默认串口模式，`--udp` 以太网模式（旧 bit），`--demo` 演示模式 |
| `device.py` | 串口/UDP 设备类、`StreamParser`（帧与示波器包切分）、帧格式常量 |
| `main_window.py` | 主界面：锁相环设置、振荡器设置、解调滤波、信号发生器、时基标定、应力计算、绘图 |
| `scope_window.py` | V5/V6 示波器窗口（自动重发 SCAP 的 watchdog） |
| `stress_calc.py` | 光弹应力计算 |

打包：`lockin_gui.spec` + `build_portable.bat`（PyInstaller，onedir 绿色包）。

### 5.2 C++ SDK（`lockin_sdk_cpp/`）

- `LockinDevice` 类：串口连接、振荡器 / DAC / 示波器 / 数据流 API，线程安全。
- 内部一个接收线程，解析应答、数据帧、示波器包；命令串行化并等待应答。
- 只依赖 Win32 API + C++17；配套 `tests/fake_fpga.py` 可无板子测试。
- 详细用法见 `lockin_sdk_cpp/README.md`。
