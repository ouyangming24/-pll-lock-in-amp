# 09 AD7606C 读数错位（示波器偶发 ~1.9 V）问题与修改记录

- **日期**: 2026-10-29
- **状态**: ⚠ 已改 RTL，待重新综合、上板验证
- **SDK / GUI / 协议**: **未改**（帧格式、示波器包、命令均不变）

---

## 1. 现象

示波器某一通道（V5 或 V6）波形上，时不时出现一个（或少数）电压异常低的点，幅度约 **1.9 V**。

用户排查后确认：**不是**该通道输入瞬间开路（原因 A），更符合 **并口读通道错位**（原因 B）。

## 2. 原因分析

### 2.1 为什么是 ~1.9 V

AD7606C 模拟输入偏置约为 2 V（数据手册：输入电流 \((V_{IN}-2)/R_{IN}\)，\(R_{IN}\approx 1\,\mathrm{M}\Omega\)）。  
**悬空**的输入读数落在约 1.9～2.0 V。未接线的 V6/V7/V8 也是这个水平。

因此偶发的 1.9 V 点，很像某一瞬间把**邻居悬空通道**的码读进了当前示波器通道。

### 2.2 为何判为读数错位（B）而非接触不良（A）

| 判据 | A 本通道断开 | B 读错通道 |
|---|---|---|
| 异常电压 | ~1.9 V（本通道悬空） | ~1.9 V（读到悬空邻居） |
| 用户结论 | 已排除 | **倾向此因** |
| 板级条件 | — | AD7606C 经飞线/转接，BUSY/RD 易毛刺 |

出错发生在 **`ad7606c_drv` 并口读数** 写入 `data5`/`data6` 之时；之后 `scope_cap` 与串口整包上传只是如实送出已错的样点。

### 2.3 排除：串口打包方式

- 示波器包有 CRC，传输出错会**整包丢弃**，不会单独冒出一个 1.9 V 点。
- 改成“逐点上传”**不能**消除 B，只会加重串口负担。故**不改**传输协议。

## 3. 修改内容（仅 `ad7606c_drv.v`）

### 3.1 加长 RD 低电平、缩短高电平（总周期不变）

| 参数 | 原值 | 新值 | 说明 |
|---|---|---|---|
| `RD_LOW_CYC` | 4 | **5** | 多给 ~15 ns 建立时间，缓解飞线延迟 |
| `RD_HIGH_CYC` | 2 | **1** | 仍 ≥ tHP_RD（10 ns）；**RD 总周期仍为 6 拍** |
| 8 通道读数时长 | 48 拍 | **48 拍** | 不挤占下一轮 BUSY↓（1 MSPS 窗口） |

### 3.2 BUSY 下降沿毛刺滤波

新增参数 `BUSY_LOW_STABLE = 2`：同步后的 BUSY 必须**先见高，再连续 2 拍为低**，才启动 CS/RD。  
抑制飞线上的窄毛刺导致的“假 BUSY↓ → 错位读数”。

### 3.3 FRSTDATA 错位：本轮不发布

- 仍置位粘滞标志 `frst_err`（帧内 `lock_flags` bit4，上位机可查）。
- **新增**：本轮任一路 FRSTDATA 与通道号不符时，置 `frst_bad_shot`，该轮**不更新** `data1..data8`、**不拉** `conv_done`，保持上一组有效数据。
- 示波器（`smp_valid = conv_done`）该微秒不写入错误点；锁相链多保持一个样点，可接受。

## 4. 未改动的部分

- `lock_in_amp.v`、示波器、`usb_commend`、串口协议  
- Python GUI、C++ SDK  
- 上位机无需重装或重编译（换 bit 即可）

## 5. 验证步骤（上板）

1. Vivado 重新综合 / 实现 / 生成 bitstream，下载。  
2. 看 `lock_flags`：正常应为 bit2=1、bit3=0、bit4=0、ID=0x31。若 bit4 仍会变 1，说明错位仍偶发，但波形尖峰应减少或消失。  
3. 示波器长时间抓 V5/V6，确认 ~1.9 V 毛刺是否消失或明显减少。  
4. （建议）未用通道 V7/V8（及不用的示波器通道）接 GND，减轻错位时的 1.9 V 外观，并降低干扰。  
5. 若仍频繁 `frst_err`：继续缩短 BUSY/RD 飞线，或把 `BUSY_LOW_STABLE` 增至 3（需再核算 1 MSPS 时序余量）。

## 6. 回退

恢复 `ad7606c_drv.v` 中：

- `RD_LOW_CYC=4`, `RD_HIGH_CYC=2`
- 去掉 BUSY 滤波与 `frst_bad_shot` 发布门控

或从 git 还原该文件后重出 bit。
