## 命令一览

格式 `NAME:十进制\r\n`；`XYOUT`、`stop` 无参数。成功回 `Command Success!`，命令名不认识回 `Command Error!`。

| 类别 | 命令 |
|---|---|
| 数据流 | `XYOUT`，`stop` |
| PLL | `FRQ2`（通道1 起点），`FRQ3`（通道2 起点，**无默认值**），`KP` 500，`KI` 50，`TAU1X/1Y/2X/2Y` 20/8/20/8，`LOCKSWY` 100000，`LOCKTHX` 300000 |
| 参考模式 | `REFMODE` 0 = 手动，1 = 自动 |
| 振荡器1/2/3 | `FRQ21/12/11`，`TAU21/12/11`，`ORD21/12/11`，`OSC1~3`，`OHN1~3`，`OSRC1~3` |
| 振荡器4~7 | `FRQ4~7`，`TAU4~7`，`ORD4~7`，`OSC4~7`，`OHN4~7`，`OSRC4~7` |
| DC | `TAUDC`，`ORDDC` |
| DAC | `DMOD` 0~6，`DWAV` 0 正弦/1 方波，`DAMP` 0~65535，`DOFS` 14 位补码 |
| 示波器 | `SDEC` n，`STLV` 码+32768，`SCAP` 触发方式 + 8×Normal |
| 无效 | `FREQ`，`PHAS`，`DFRQ`，`DPHS` |

参数编码：`OSCk` = n×256 + m；`OSRCk` 0 = V3，1 = V4，2 = V3−V4；`TAU` 0~31；`ORD` 1~4；`OHN` 0 当作 1。

`SCAP`：0 立即，1 V5↑，2 V5↓，3 V6↑，4 V6↓；加 8 = Normal（不强制触发）。

## 换算公式

| 换算 | 公式 |
|---|---|
| 频率字 → Hz | word × 65e6 / 2⁴⁸ |
| X/Y → V | × 0.9966 / 1 859 440 ≈ × 5.36e-7 |
| ch3_dc → V | × 2.203e-3 |
| adc_chN（14 位）→ V | × 10/8192 |
| 示波器码（16 位）→ V | × 10/32768 |
| DAC 幅度 | Vpk ≈ 3.0 × DAMP/65535 |
| DOFS | 码 ≈ V / 3.0 × 8191，负数发 `码 & 0x3FFF` |
| 示波器 dt | (SDEC + 1) µs；t[i] = (i − 128) × dt |
| sample_cnt → s | × 1e-6（标称） |

## TAU 对照（一阶，fs = 1 MHz）

α = 2^-tau，时间常数 ≈ 2^tau µs，每加 1 档约翻倍。

| tau | fc (−3 dB) | 时间常数 |
|---|---|---|
| 2 | 46 kHz | 3.5 µs |
| 8 | 623 Hz | 0.26 ms |
| 12 | 38.9 Hz | 4.1 ms |
| 16 | 2.43 Hz | 65.5 ms |
| 20 | 0.152 Hz | 1.05 s |

n 阶级联时，−3 dB 频率约为一阶的 √(2^(1/n) − 1) 倍（2 阶约 0.64，3 阶约 0.51，4 阶约 0.43）。
