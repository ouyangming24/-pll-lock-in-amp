# 一阶低通滤波器：从电路到数字滤波器的完整推导

> 本文从最基础的 RC 电路出发，完整推导一阶低通滤波器的传递函数、幅频/相频响应、截止频率、巴特沃斯滤波器、双线性变换、指数移动平均（EMA）、微分方程、阶跃响应、稳定时间、等效噪声带宽（ENBW）、噪声系数（NF）与 ADC 有效位数（ENOB），将整条知识链一次打通。

> **α 约定（全文统一，与 `iir_lpf_ema` 一致）：**  
> $\alpha$ = **当前输入的权重**（平滑因子），$0<\alpha\le 1$。窄带滤波时 $\alpha\ll 1$。  
> $$y[n]=\alpha\,x[n]+(1-\alpha)\,y[n-1]=\;y[n-1]+\alpha\bigl(x[n]-y[n-1]\bigr)$$  
> 极点为 $1-\alpha$。硬件中 $\alpha=2^{-k}$（`shift_k`）。  
> （注：部分文献把靠近 1 的极点系数也叫 α，本文不采用该写法，以免与后向欧拉公式冲突。）

## 一、RC 电路与传递函数

### 1.1 电路结构

最基础的一阶低通滤波器由电阻 $R$ 和电容 $C$ 组成：

```
Vin ── R ───┬──── Vout
             |
             C
             |
            GND
```

输出取自电容两端。对地电容的作用是：**高频经电容旁路到地被衰减，低频（含直流）几乎无损通过**；电容电压不能突变，故输出对阶跃呈指数上升。

### 1.2 从阻抗推导传递函数

电容阻抗（s 域）：
$$Z_C = \frac{1}{sC}$$

用分压公式：
$$H(s) = \frac{V_{out}(s)}{V_{in}(s)} = \frac{Z_C}{R + Z_C} = \frac{\frac{1}{sC}}{R + \frac{1}{sC}}$$

分子分母同乘 $sC$：
$$H(s) = \frac{1}{1 + sRC}$$

定义 **截止角频率**：
$$\omega_c = \frac{1}{RC}$$

传递函数写成标准形式：
$$\boxed{H(s) = \frac{1}{1 + \frac{s}{\omega_c}}}$$

- 直流增益 $K = 1$（电容开路，输出 = 输入）
- 一个极点 $s = -\omega_c$，位于左半平面 → 稳定

## 二、频率响应：幅频与相频

### 2.1 代入 $s = j\omega$

$$H(j\omega) = \frac{1}{1 + j\frac{\omega}{\omega_c}}$$

这是一个复数，可以拆成幅值和相位。

### 2.2 幅频响应（增益公式）

复数模长：
$$|H(j\omega)| = \frac{1}{\sqrt{1 + \left(\frac{\omega}{\omega_c}\right)^2}}$$

工程上用 dB 表示：
$$A(\omega) = 20\log_{10}|H(j\omega)| = -20\log_{10}\sqrt{1 + \left(\frac{\omega}{\omega_c}\right)^2}$$

$$\boxed{A(\omega) = -10\log_{10}\left[1 + \left(\frac{\omega}{\omega_c}\right)^2\right] \ \text{(dB)}}$$

### 2.3 三个关键点

| 频率 | 增益 | 说明 |
|---|---|---|
| $\omega \ll \omega_c$ | ≈ 0 dB | 低频几乎无衰减 |
| $\omega = \omega_c$ | $-3.01$ dB | 截止频率 |
| $\omega \gg \omega_c$ | $-20\log_{10}(\omega/\omega_c)$ | 每十倍频衰减 20 dB |

👉 **一阶滤波器 = -20 dB/dec 滚降**

### 2.4 相频响应

复数辐角：
$$\angle H(j\omega) = -\angle(1 + j\frac{\omega}{\omega_c}) = -\tan^{-1}\left(\frac{\omega}{\omega_c}\right)$$

$$\boxed{\phi(\omega) = -\tan^{-1}\left(\frac{\omega}{\omega_c}\right)}$$

| 频率 | 相位 |
|---|---|
| $\omega \to 0$ | $0^\circ$ |
| $\omega = \omega_c$ | $-45^\circ$ |
| $\omega \to \infty$ | $-90^\circ$ |

**为什么是负的？** 电容电压滞后电流 → 输出取自电容 → 输出滞后输入 → 相位恒为负（滞后）。

### 2.5 群延迟

$$\tau_g(\omega) = -\frac{d\phi}{d\omega} = \frac{1}{\omega_c\left[1 + \left(\frac{\omega}{\omega_c}\right)^2\right]}$$

在 $\omega = 0$ 处群延迟最大：$\tau_g(0)=\dfrac{1}{\omega_c}=\tau$；  
在 $\omega = \omega_c$ 处：$\tau_g(\omega_c)=\dfrac{1}{2\omega_c}=\tau/2$。

👉 **一阶低通的群延迟在直流处最大，随频率单调下降**（并非在截止频率处最大）。

## 三、截止频率的物理意义

### 3.1 -3 dB 从哪来？

$|H(j\omega_c)| = \dfrac{1}{\sqrt{2}}$

功率 = 幅值平方：
$$P = |H|^2 = \frac{1}{2}$$

功率减半 = **-3.01 dB**。

物理含义：**信号功率在截止频率处衰减为一半**。

### 3.2 时间常数 $\tau$

$$\tau = RC = \frac{1}{\omega_c}$$

- 阶跃响应从 0 涨到 63.2% 所需时间
- 系统"惯性"的度量
- 记忆长度的核心参数

## 四、巴特沃斯滤波器怎么来的

### 4.1 问题：一阶滚降太慢

一阶 -20 dB/dec 不够陡，高频噪声抑制不足。需要**更高阶、更平坦的通带、更陡的过渡带**。

### 4.2 巴特沃斯的设计思想

巴特沃斯滤波器（Butterworth, 1930）的核心目标：

> **通带内幅频响应尽可能平坦（最平滑），截止频率处 -3 dB，过渡带单调下降。**

### 4.3 数学推导

巴特沃斯低通幅频平方：
$$|H(j\omega)|^2 = \frac{1}{1 + \left(\frac{\omega}{\omega_c}\right)^{2N}}$$

其中 $N$ 是滤波器阶数。

- $N=1$：一阶低通（就是我们的 RC 滤波器）
- $N=2$：二阶，通带更平，过渡更陡
- $N$ 越大：越接近理想矩形

### 4.4 从幅频到传递函数

将 $\omega \to s/j$：
$$|H(s)|^2 = H(s)H(-s) = \frac{1}{1 + \left(\frac{s}{j\omega_c}\right)^{2N}}$$

极点满足 $s^{2N} = -(j\omega_c)^{2N}$，分布在左半平面的 $N$ 个极点构成 $H(s)$。

**一阶（N=1）的极点**：$s = -\omega_c$ → 就是 RC 低通。

### 4.5 巴特沃斯 vs 一阶对比

| 特性 | 一阶（= 巴特沃斯 N=1） | 巴特沃斯 N 阶 |
|---|---|---|
| 滚降 | -20 dB/dec | -20N dB/dec |
| 通带平坦度 | — | 在给定阶数下最平坦 |
| 相位线性 | 较好 | $N\ge 2$ 有复极点，相位更复杂 |
| ENBW/$f_c$（相对各自 -3 dB 的 $f_c$） | 1.571 | $N=2$ 时约为 **1.111**（$\pi/(2\sqrt{2})$），随 $N$ 增大趋近 1 |

说明：两个**相同**一阶节级联（非巴特沃斯）时，若仍用单节的 $\omega_0$ 定义积分，噪声带宽因子可为 $\pi/4\approx 0.785$，但级联后的 -3 dB 点已下移，不可与巴特沃斯 $N=2$ 混用。

## 五、离散化：从 s 域到 z 域

### 5.1 为什么需要离散化？

数字处理器只能做差分方程，不能直接解微分方程。需要把 $H(s)$ 变成 $H(z)$。

### 5.2 三种常用离散化方法

#### 方法一：后向欧拉（最常用，→ EMA）

$$s \leftarrow \frac{1 - z^{-1}}{T}$$

代入 $H(s) = \dfrac{1}{1 + s/\omega_c}$：

$$H(z) = \frac{1}{1 + \frac{1}{\omega_c}\cdot\frac{1-z^{-1}}{T}} = \frac{\omega_c T}{\omega_c T + 1 - z^{-1}}$$

令 $\alpha = \dfrac{\omega_c T}{1 + \omega_c T}$，则：

$$\boxed{H(z) = \frac{\alpha}{1 - (1-\alpha)z^{-1}}}$$

时域差分方程（由 $Y=\alpha X+(1-\alpha)z^{-1}Y$）：
$$\boxed{y[n] = \alpha\,x[n] + (1-\alpha)\,y[n-1]}$$

等价增量形式（与 `iir_lpf_ema` 一致）：
$$\boxed{y[n] = y[n-1] + \alpha\bigl(x[n]-y[n-1]\bigr)}$$

**这就是指数移动平均（EMA）。** 窄带时 $\alpha\ll 1$，硬件常取 $\alpha=2^{-k}$。

#### 方法二：前向欧拉（不稳定，不推荐）

$$s \leftarrow \frac{z-1}{T}$$

极点可能跑到单位圆外 → 不稳定。

#### 方法三：双线性变换（Tustin，→ 一阶 IIR 但非 EMA）

$$s = \frac{2}{T}\frac{1-z^{-1}}{1+z^{-1}}$$

代入 $H(s)=\omega_c/(s+\omega_c)$ 后，分子分母都含 $(1+z^{-1})$，结构为：

$$y[n] = a\,y[n-1] + b\bigl(x[n] + x[n-1]\bigr)$$

**不是 EMA 形式**（多了 $x[n-1]$ 前馈项）。频率映射更好，配合预扭曲（prewarping）可精确匹配指定截止频率，但实现更重，见 §5.4。

### 5.3 三种方法对比

| 方法 | 稳定性 | 是否 EMA | 频率映射 |
|---|---|---|---|
| 后向欧拉 | ✅ 稳定 | ✅ 是 | 低频准确，高频压缩 |
| 前向欧拉 | ❌ 可能不稳 | ❌ | 差 |
| 双线性 | ✅ 稳定 | ❌ | 全频段较好（需预扭曲） |

### 5.4 为什么工程上常用 EMA，而不是双线性？

双线性**理论上完全可用**，并不是“错的”。在锁相放大器后级、FPGA 定点实现、极窄带提直流这类场景里，选 EMA / 后向欧拉是因为**需求匹配、实现成本低**，不是因为双线性频率映射更差就否定它。

#### （1）实现成本：移位 vs 通用乘法

| | EMA（后向欧拉） | 双线性一阶 |
|---|---|---|
| 递推 | $y\leftarrow y+(x-y)\cdot\alpha$ | $y\leftarrow a y + b(x[n]+x[n-1])$ |
| 状态 | 只需 $y[n-1]$ | 还需保存 $x[n-1]$ |
| 系数 | 常取 $\alpha=2^{-k}$，**算术右移**即可 | $a,b$ 一般需乘法器 / 多比特移位组合 |
| FPGA 资源 | 极少（本仓库 `iir_lpf_ema`） | 明显更多 |

#### （2）行为直观，与商用 LIA 一致

- EMA ≡ 离散 RC：阶跃**无过冲**、$\tau\approx T/\alpha$、$t_s\approx\tau\ln(1/\varepsilon)$ 好算。
- 商用锁相（如 SR830）的 6/12/18/24 dB/oct，通常是**相同时间常数的一阶 RC 级联**，不是双线性巴特沃斯。本工程 `iir_lpf_cascade` 走同一路线。

#### （3）真正要优化的不是“贴模拟曲线”

LIA 数字后级优先关心：

- DC 增益 = 1（无偏提直流）
- 可调噪声带宽 / ENBW
- 稳定时间可估
- 资源与延迟可控

**不要求**把模拟 $f_c$、相位曲线贴到很高精度。双线性的优势（全频段映射准、预扭曲对 -3 dB）主要服务音频 EQ、抗混叠设计等“必须复现模拟频响”的场合。

#### （4）窄带时两者几乎一样

当 $f_c\ll f_s$（CIC 降采样后往往成立）时，后向欧拉与双线性的频响差别很小；换双线性**几乎买不到更好的 SNR / 稳定时间**，却增加复杂度和资源。

#### （5）什么时候更该用双线性？

- $f_c$ 接近 $f_s/2$，后向欧拉高频畸变明显
- 必须严格复现某模拟滤波器的 -3 dB / 相位
- 高阶 IIR（巴特沃斯等）：双线性 + 预扭曲是主流设计路径

> **结论：** 一阶 + 极窄带 + 移位实现 → **EMA / 后向欧拉**是更合适的工程选择；双线性不是理论更优或更劣，而是**场景不同**。

## 六、指数移动平均（EMA）的本质

### 6.0 EMA 是从双线性推出来的吗？

**不是。** EMA 作为递推定义更早独立存在；与模拟 RC 的联系是后来对上的。双线性一般也**推不出**标准 EMA。

1. **统计 / 时间序列侧（定义在先）**  
   指数平滑（Brown 等，1950 年代起）直接定义：对新样本加权、对历史指数衰减，或写成  
   $$y[n]=\alpha x[n]+(1-\alpha)y[n-1]$$  
   动机是预测与平滑，**不是**从 $H(s)$ 离散化推出来的。

2. **滤波 / 控制侧（后来等价）**  
   一阶 RC 用**后向欧拉**（或极点匹配）离散化后，正好得到同一个递推。  
   因此是「两条线汇合」，不是「先有模拟滤波 → 双线性 → 才发明 EMA」。

3. **和双线性的关系**  
   见 §5.2 方法三与 §5.4：双线性一阶带 $x[n]+x[n-1]$ 前馈，**不是** EMA；本仓库硬件走 EMA / 后向欧拉（$\alpha=2^{-k}$）。

### 6.1 定义

标准 EMA（本文约定：$\alpha$ 为**输入权重**）：
$$y[n] = \alpha\,x[n] + (1-\alpha)\,y[n-1], \quad 0 < \alpha \le 1$$

### 6.2 展开看"指数"

反复迭代：
$$
\begin{aligned}
y[n] &= \alpha\,x[n] + (1-\alpha)\,y[n-1] \\
&= \alpha\,x[n] + (1-\alpha)\alpha\,x[n-1] + (1-\alpha)^2\alpha\,x[n-2] + \cdots
\end{aligned}
$$

通式：
$$y[n] = \sum_{k=0}^{\infty} \alpha\,(1-\alpha)^k\, x[n-k]$$

**权重 $w_k = \alpha\,(1-\alpha)^k$ 按指数衰减** → 指数加权移动平均。

### 6.3 和普通移动平均（MA）对比

| | 窗口平均 MA | 指数移动平均 EMA |
|---|---|---|
| 权重 | 等权，突然截断 | 指数衰减，无截断 |
| 实现 | 存 N 个样本 | 只需 1 个状态 y[n-1] |
| 类型 | FIR | IIR（一阶） |
| 记忆 | 有限 N | 理论无限（指数遗忘） |

### 6.4 为什么"递归"等价于"无限历史"

EMA 的无穷级数需要无限 memory，但递归形式只用 $y[n-1]$ 就压缩了所有历史信息。

> **IIR 的本质：用状态代替历史。**

### 6.5 α 的直觉含义（输入权重约定）

- $\alpha \to 0$：几乎不采信新样本，记忆长，平滑强，响应慢（窄带）
- $\alpha \to 1$：几乎只用当前输入，平滑弱，响应快（接近直通）

与硬件对应：$\alpha=2^{-k}$，$k$ 越大 α 越小，滤波越强。

## 七、α 与截止频率的对应关系

### 7.1 精确公式（后向欧拉）

$$\boxed{\alpha = \frac{\omega_c T}{1 + \omega_c T} = \frac{2\pi f_c / f_s}{1 + 2\pi f_c / f_s}}$$

反解：
$$\boxed{f_c = \frac{f_s}{2\pi}\cdot\frac{\alpha}{1-\alpha}}$$

### 7.2 工程近似（低频，最常用）

当 $f_c \ll f_s$（几乎总是成立）：
$$\boxed{\alpha \approx 2\pi\frac{f_c}{f_s}}$$
$$\boxed{f_c \approx \frac{\alpha f_s}{2\pi}}$$

### 7.3 匹配 z 变换（冲激不变 / 零极点匹配）的另一种对应

连续极点 $e^{-\omega_c T}$ 映射为离散极点，故

$$1-\alpha = e^{-\omega_c T} \quad \Rightarrow \quad \alpha = 1-e^{-\omega_c T}$$

当 $\omega_c T\ll 1$ 时 $\alpha\approx\omega_c T$，与后向欧拉低频近似一致。

反解截止频率：
$$f_c = -\frac{f_s}{2\pi}\ln(1-\alpha)$$

### 7.4 三种对应方法总结

| 方法 | α（输入权重）公式 | 特点 |
|---|---|---|
| 后向欧拉（最常用） | $\alpha=\dfrac{\omega_c T}{1+\omega_c T}$ | 控制/嵌入式默认；→ EMA |
| 低频近似 | $\alpha \approx \omega_c T = 2\pi f_c/f_s$ | 手算；要求 $f_c\ll f_s$ |
| 极点匹配 | $\alpha = 1-e^{-\omega_c T}$ | 连续时间常数更忠实 |

### 7.5 验证举例

$f_s = 1000$ Hz，$f_c = 10$ Hz：
$$\alpha = \frac{2\pi\times 10/1000}{1 + 2\pi\times 10/1000} \approx 0.0591$$

（若误把 α 当成极点系数，会得到 $\approx 0.94$，与上式及硬件 $2^{-k}$ 量级都不一致。）

## 八、微分方程视角

### 8.1 RC 电路的微分方程

电容电流：$i = C\dfrac{dv_{out}}{dt}$

回路方程：$v_{in} = iR + v_{out} = RC\dfrac{dv_{out}}{dt} + v_{out}$

$$\boxed{RC\frac{dv_{out}}{dt} + v_{out} = v_{in}}$$

### 8.2 拉普拉斯变换 → 传递函数

假设零初始条件，对两边做拉普拉斯变换：

$$RC\cdot s V_{out}(s) + V_{out}(s) = V_{in}(s)$$

$$V_{out}(s)(1 + sRC) = V_{in}(s)$$

$$H(s) = \frac{V_{out}}{V_{in}} = \frac{1}{1 + sRC}$$

和前面分压法结果一致。

### 8.3 从微分方程到差分方程（数字域）

后向欧拉：$\dfrac{dv}{dt} \approx \dfrac{y[n] - y[n-1]}{T}$

代入 $RC\dfrac{dy}{dt} + y = x$：

$$RC\frac{y[n]-y[n-1]}{T} + y[n] = x[n]$$

整理：
$$y[n]\left(1 + \frac{RC}{T}\right) - \frac{RC}{T}y[n-1] = x[n]$$

$$y[n] = \frac{T}{RC+T}\,x[n] + \frac{RC}{RC+T}\,y[n-1]$$

令（注意：是 $T/(RC+T)$，不是 $RC/(RC+T)$）
$$\alpha = \frac{T}{RC+T} = \frac{\omega_c T}{1 + \omega_c T}$$

则
$$\boxed{y[n] = \alpha\,x[n] + (1-\alpha)\,y[n-1]}$$

👉 **从微分方程出发，离散化后自然得到 EMA，没有任何人为假设。**

### 8.4 连续 vs 离散对照

| | 连续（模拟） | 离散（数字） |
|---|---|---|
| 方程 | $RC\dot{y} + y = x$ | $y[n]=\alpha x[n]+(1-\alpha)y[n-1]$ |
| 指数底（误差衰减） | $e^{-t/RC}$ | $(1-\alpha)^n$ |
| 时间常数 | $\tau = RC$ | $\tau \approx T/\alpha$（$\alpha\ll 1$） |
| 本质 | 连续指数遗忘 | 离散指数遗忘 |

## 九、阶跃响应与稳定时间

### 9.1 连续阶跃响应

输入单位阶跃 $x(t) = A\cdot u(t)$，解微分方程：

$$y(t) = A(1 - e^{-t/\tau}), \quad \tau = RC$$

### 9.2 稳定时间定义

> 阶跃输入后，输出进入并保持在"终值 ±ε"带内的最短时间。

$$e^{-t_s/\tau} = \varepsilon \quad \Rightarrow \quad \boxed{t_s = \tau\ln\frac{1}{\varepsilon}}$$

常用值：
- 1% (ε=0.01)：$t_s \approx 4.61\tau$
- 0.1% (ε=0.001)：$t_s \approx 6.91\tau$
- N 位精度 (ε=2⁻ᴺ)：$t_s \approx 0.693N\tau$

### 9.3 数字 EMA 阶跃响应

初值 $y[-1]=0$，输入 $x[n]=A$（$n\ge 0$）：

$$y[n] = A\bigl(1 - (1-\alpha)^{n+1}\bigr)$$

若将 $n$ 记为更新次数且约定第 $n$ 次更新后（等价写法，常用）：

$$y[n] = A\bigl(1 - (1-\alpha)^n\bigr)$$

相对误差 $e[n]=(1-\alpha)^n$。稳定到 ε：

$$(1-\alpha)^{n_s} \le \varepsilon \quad \Rightarrow \quad \boxed{n_s = \left\lceil\frac{\ln\varepsilon}{\ln(1-\alpha)}\right\rceil}$$

当 $\alpha\ll 1$ 时 $\ln(1-\alpha)\approx -\alpha$，故

$$\boxed{n_s \approx \frac{\ln(1/\varepsilon)}{\alpha} = (-\ln\varepsilon)\cdot 2^{k}\quad(\alpha=2^{-k})}$$

物理时间：$t_s = n_s \cdot T$，且 $t_s \approx \tau\ln(1/\varepsilon)$（与连续一致）。

**常见错误：** 写成 $\alpha^{n_s}\le\varepsilon$ 或 $y=A(1-\alpha^n)$——那是把 α 当成极点（≈1）的另一套记号；与本文及后向欧拉的 $\alpha=\omega_c T/(1+\omega_c T)$ 矛盾。
### 9.4 稳定时间与幅值的关系

**理想一阶系统：无关。**

$$\frac{|y(t)-A|}{A} = e^{-t/\tau}$$

幅值 A 被约掉了 → 相对误差收敛时间只取决于 τ。

**但现实中有关：**
- 运放压摆率限制（大信号时 SR 主导）
- ADC 的 LSB 是绝对误差（小信号更难稳）
- 非线性/饱和

含 SR 的工程公式：
$$t_s \approx \frac{A}{SR} + \tau\ln\frac{1}{\varepsilon} \quad (\text{大信号})$$

### 9.5 稳定时间 vs 信号频率（重要！）

❌ **不能用 $f < 1/t_s$ 判断能否跟上**

正确判据：
- 时域：$2\pi f \tau \ll 1$ 或 $f \ll f_c$
- 频域：看幅频曲线，信号频率应远小于截止频率 $f_c$

| 判据 | 用途 |
|---|---|
| $t_s = \tau\ln(1/\varepsilon)$ | 阶跃后多久"静下来" |
| $f_c = 1/(2\pi\tau)$ | 多快的信号还能"跟得上" |

二者相差约 $2\pi$ 倍，**不能互相替代**。

## 十、稳定时间与信号频率的关系

### 10.1 时域跟踪条件

正弦信号 $x(t) = A\sin(2\pi ft)$，最大斜率：
$$\left|\frac{dx}{dt}\right|_{\max} = 2\pi f A$$

系统最大自然变化率：$\dfrac{A}{\tau}$

跟踪条件：
$$2\pi f \tau \ll 1 \quad \Leftrightarrow \quad f \ll f_c$$

### 10.2 频域验证

| 需求 | 频率关系 |
|---|---|
| 无失真跟踪 | $f < 0.1 f_c$ |
| 可接受幅衰 | $f < f_c$ |
| 仅能量通过 | $f \lesssim f_c$ |

### 10.3 工程口诀

> **稳不住看 $t_s$，跟不上看 $f_c$。**  
> 稳：指数收敛，用 τ 算时间；  
> 跟：正弦响应，用 $f_c$ 算带宽。

## 十一、等效噪声带宽（ENBW）

### 11.1 定义

> 一个理想矩形低通滤波器的带宽，它在白噪声输入下，输出的噪声功率和实际滤波器完全一样。

### 11.2 数学定义

输出噪声功率（单边 PSD = $N_0$）：
$$P_n = N_0 \int_0^{\infty} |H(j\omega)|^2 d\omega$$

等效噪声带宽：
$$\boxed{B_n = \frac{\int_0^{\infty} |H(j\omega)|^2 d\omega}{|H(0)|^2}}$$

### 11.3 一阶低通的 ENBW

$$|H(j\omega)|^2 = \frac{1}{1+(\omega/\omega_c)^2}$$

$$B_n = \int_0^{\infty} \frac{d\omega}{1+(\omega/\omega_c)^2} = \omega_c \cdot \frac{\pi}{2}$$

换回 Hz（$\omega_c = 2\pi f_c$）：
$$\boxed{B_n = \frac{\pi}{2}f_c \approx 1.571\ f_c}$$

### 11.4 数字 EMA 的 ENBW

本文约定下 $H(z)=\dfrac{\alpha}{1-(1-\alpha)z^{-1}}$，故

$$|H(e^{j\Omega})|^2 = \frac{\alpha^2}{1 - 2(1-\alpha)\cos\Omega + (1-\alpha)^2}$$

对单位功率白噪声，输出功率增益为 $\displaystyle\sum_k h[k]^2 = \dfrac{\alpha}{2-\alpha}$。  
单边等效噪声带宽（相对采样率 $f_s$）常用写法：

$$\boxed{B_{n,\text{dig}} = \frac{\alpha}{2-\alpha}\cdot \frac{f_s}{2}}$$

（等价：若改用极点 $p=1-\alpha$，则 $B_n=\dfrac{1-p}{1+p}\cdot\dfrac{f_s}{2}$，与上式相同。）

低频近似 $\alpha\approx 2\pi f_c/f_s\ll 1$ 时：

$$B_{n,\text{dig}}\approx \frac{\alpha}{2}\cdot\frac{f_s}{2}=\frac{\alpha f_s}{4}=\frac{\pi}{2}f_c$$

与模拟一阶 ENBW 一致。
### 11.5 不同滤波器的 ENBW

| 滤波器 | ENBW / $f_c$（相对该滤波器自己的 -3 dB 频率） |
|---|---|
| 理想矩形 | 1.000 |
| 一阶低通 | **1.571**（$\pi/2$） |
| 二阶巴特沃斯 | **1.111**（$\pi/(2\sqrt{2})$） |
| 两节相同一阶级联（按单节 $\omega_0$ 积分） | 0.785（$\pi/4$）；注意级联后 -3 dB 点已变 |
| 高斯 | ~1.05 |

👉 滚降越慢，高频拖尾贡献越多噪声，ENBW 相对 -3 dB 带宽越大。

## 十二、ENBW、噪声系数与 ENOB 的统一

### 12.1 信号链全貌

```
传感器/源 → 模拟前端(RC低通, ENBW) → 放大器(NF) → ADC(SNR, ENOB)
```

### 12.2 热噪声 + ENBW

源阻抗 $R_s$，室温 $T = 290$ K：
$$N_0 = 4kTR_s \quad [\text{W/Hz}]$$

通过 ENBW = $\dfrac{\pi}{2}f_c$ 的低通后：
$$\overline{v_n^2} = 4kTR_s \cdot B_n$$

### 12.3 噪声系数（NF）

$$\text{NF} = 10\log_{10}\left(\frac{\text{实际输出噪声}}{\text{仅源热噪声输出}}\right)$$

系统噪底（dBm）：
$$\boxed{N_{\text{floor}} = -174\ \text{dBm/Hz} + \text{NF} + 10\log_{10}(B_n)}$$

- $-174$ dBm/Hz = $kT$（室温单边）
- NF 是"倍数"，最终噪声还要乘 ENBW

### 12.4 ADC 量化噪声与 ENOB

理想 N 位 ADC：
$$\text{SNR}_{\text{ideal}} = 6.02N + 1.76\ \text{dB}$$

实际 ENOB：
$$\boxed{\text{ENOB} = \frac{\text{SNR}_{\text{actual}} - 1.76}{6.02}}$$

量化噪声（rms）：
$$V_q = \frac{\text{LSB}}{\sqrt{12}} = \frac{V_{\text{ref}}}{2^N\sqrt{12}}$$

### 12.5 完整系统 SNR

总噪声 = 前端噪声（含 ENBW）+ 量化噪声：
$$V_{n,\text{total}} = \sqrt{4kTR_s \cdot F \cdot B_n + V_q^2}$$

$$\text{SNR} = 20\log_{10}\left(\frac{V_{\text{signal,rms}}}{V_{n,\text{total}}}\right)$$

### 12.6 各量的角色总结

| 量 | 角色 |
|---|---|
| ENBW | 噪声积分窗口（前端噪声多少） |
| NF | 窗口内源热噪声被放大多少倍 |
| ENOB | ADC 在总噪声下能分辨几位 |
| $f_c$ / α / τ | 决定 ENBW 的大小 |

### 12.7 设计直觉

- **加 RC 低通（缩小 ENBW）** → 前端噪底 ↓ → ENOB ↑（若原来受模拟噪底限制）
- **降 NF** → 只帮源热噪声部分，对量化噪声无效
- **过采样但不抗混叠** → ENBW 变宽 → 噪底 ↑ → ENOB ↓

## 附录：完整推导链一览

```
RC 电路
  │  分压 / 基尔霍夫定律
  ▼
H(s) = 1/(1 + s/ωc)          ← 传递函数
  │  s = jω
  ▼
|H(jω)|, φ(ω)                 ← 幅频 & 相频
  │  模长 → dB, 辐角 → 相位
  ▼
-3 dB 点 = ωc = 1/RC           ← 截止频率
  │  微分方程 RC·ẏ + y = x
  ▼
后向欧拉离散化                 ← s → (1-z⁻¹)/T  （非双线性；选型理由见 §5.4）
  │
  ▼
y[n]=α x[n]+(1-α)y[n-1]   ← EMA（指数移动平均；定义先于滤波离散化，见 §6.0）
  │  展开 → Σ α(1-α)ᵏ x[n-k]
  ▼
权重 = α(1-α)ᵏ                 ← 指数衰减 ⇒ "指数"移动平均
  │  α = ωcT/(1+ωcT) ≈ 2πfc/fs ；硬件 α=2⁻ᵏ
  ▼
α ↔ fc 对应                    ← 模拟参数 ↔ 数字参数
  │  解微分方程 / 差分方程
  ▼
阶跃响应 = 1 - e^{-t/τ}        ← 指数收敛；离散误差 (1-α)ⁿ
  │  ts = τ·ln(1/ε)；ns ≈ ln(1/ε)/α
  ▼
稳定时间                       ← 4.61τ (1%), 6.91τ (0.1%)
  │  跟踪条件：fc ≫ f（不是 1/ts）
  ▼
频域判据 f ≪ fc               ← 能跟多快的信号
  │  ∫|H|²dω / |H(0)|²
  ▼
ENBW = (π/2)fc                ← 等效噪声带宽
  │  4kTRs · ENBW → 热噪声功率
  ▼
NF + ENBW → 噪底              ← 系统噪声
  │  SNR = 信号 / (前端噪声 + 量化噪声)
  ▼
ENOB = (SNR - 1.76)/6.02      ← ADC 有效位数
```

> **一句话贯穿全文：**
>
> RC 低通的"指数遗忘"本质，在连续域表现为 $e^{-t/\tau}$，离散化后误差按 $(1-\alpha)^n$ 衰减，递推式就是 EMA（$\alpha$ 为输入权重）；$\tau$ 决定稳定时间和截止频率，截止频率决定 ENBW，ENBW 决定噪底，噪底决定 ENOB——**整条链从同一个 $\tau$ 出发。**
